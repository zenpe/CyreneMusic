# 播放行为约定

列表播放统一通过 `PlayerService.playCollection` 发起，复用现有播放器事务、失败回退及最后请求优先保护。页面不再先设置队列再通过歌曲 ID 查找播放项。

## 播放全部

| 当前模式 | 按钮 | 起始歌曲 | 播放方式 |
| --- | --- | --- | --- |
| 顺序播放 | 播放全部 | 第一首 | 到末尾停止 |
| 列表循环 | 播放全部 | 第一首 | 列表循环 |
| 随机播放 | 随机播放、随机图标 | 随机一首 | 随机遍历 |
| 单曲循环 | 播放全部 | 第一首 | 切到列表循环 |

专门的随机播放按钮始终切换随机模式，不直接打乱原列表。空列表不修改队列或模式；单首列表仍遵循对应模式。失败的替换请求回退自己的模式变更，不覆盖用户随后手动选择的模式。

## 点击歌曲及队列编辑

- 歌单、专辑、榜单、每日推荐：建立完整列表队列，从选中项开始，保留模式。
- 播放队列：通过稳定队列项 ID 定位，不重建队列。相同歌曲的不同队列项可以分别选中。
- 搜索、历史的单曲播放沿用单曲入口：已在队列中则定位，否则建立单首队列。
- 添加、排序、删除非当前项均保留模式，不打断播放；每日推荐的添加操作真正追加，不重新分配整张队列的 ID。
- 下一首播放在随机遍历中优先于其它项，随后恢复原随机遍历，保留上一首历史。单曲循环不会因此解除，需手动下一首或切换模式。
- 再次把当前歌曲加入“下一首播放”不删除其正在播放的队列项。
- 删除当前项播放下一候选项；顺序模式删除末项停止，循环模式绕回第一项，随机模式使用删除前的随机候选。空队列停止。

## 自然结束与手动导航

顺序播放不绕回，列表循环绕回。单曲循环自然结束重复当前歌曲，手动上下首可以切歌并继续循环新歌曲。随机模式沿稳定遍历导航，上一首再下一首返回同一队列项。

## 私人 FM

FM 使用 `QueueSource.neteaseFm`，有效模式固定顺序播放。普通模式单独保留，退出 FM 后自动恢复。播放器、队列面板和系统媒体通知不提供普通模式切换。

接近队尾时补充推荐；追加时校验来源和尾部项，避免迟到请求污染其它队列。没有新推荐时播放完当前队列即停止，页面保留错误及换一批入口。启动恢复保留 FM 来源及普通模式，并重新绑定推荐补充任务。

## 人工验收

Windows 与 Android 各验证 Material／Fluent 等可用主题：

1. 四种模式分别点击播放全部，核对按钮、首曲和末尾行为。
2. 单曲循环点击列表中的某首，确认仍为单曲循环；手动下一首可以前进。
3. 专辑列表及网格点击歌曲，确认队列为整张专辑。
4. 随机播放插入下一首，确认优先播放，上一首再下一首仍返回该项。
5. 删除当前首项、末项、唯一项，并确认非当前项编辑不断播。
6. 快速点击不同列表，最终只播放最后一次选择；加载失败保留原播放。
7. 单曲循环进入 FM，确认连续播放、模式入口隐藏，离开后恢复原模式；重启恢复仍为 FM 顺序播放。

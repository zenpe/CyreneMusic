# 网易云账号与个性化推荐

本次发行：客户端 1.3.6+10，配合 Cyapi Go v0.0.5 或更新版本。

## 使用流程

先升级 Cyapi Go 后端，再打开客户端“设置 → 第三方账号 → 网易云 → 去绑定”。手机在 App 内官方页面登录；Windows 使用系统 WebView2 打开官方页面。支持备用二维码，手机上的二维码需另一设备使用网易云 App 扫描。

正式环境的网页登录绑定使用 HTTPS 服务器地址；本机测试仅额外允许 localhost、127.0.0.1 和 IPv6 回环地址的 HTTP。不需要填写 Cookie 或新增回调地址。绑定保存在后端，同一 Cyapi 账号的其他设备可共享。更换账号成功前保留旧绑定；取消窗口不覆盖旧账号。网易云过期提示重新绑定，不退出 Cyapi。

首页“为你推荐”提供每日推荐歌曲、每日推荐歌单和私人 FM，现有“发现”保留。日推宽屏预览 6 首、窄屏预览 3 首，支持点选播放、播放全部与查看完整列表。FM 首次进入加载歌曲预览，点击播放后启动独立队列；卡片显示封面、歌名、歌手及播放/暂停、换一批操作。

设置中的“个人歌单”支持分页、多选复制为本地或关注同步；导入对话框的网易云账号入口进入同一页面。酷狗显示“暂不支持”。所有操作只读取网易云，播放沿用原有音源。

## 验证与边界

Windows 本地真实账号绑定、个人歌单及推荐数据已取得验证反馈；上游每日推荐返回 30 首、FM 返回 3 首。修复绑定页面重绘导致重复加载，回归测试覆盖 Material/Fluent 主题以及推荐卡片的桌面和窄屏布局、点击与加载状态。

发行前 Flutter 全量静态检查通过，全量测试 662 项通过、8 项跳过；随后构建 Windows release、Android arm64 release。构建报告、文件摘要与产物保存在 build/releases 下。

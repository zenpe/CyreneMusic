# 客户端更新

采用「自动检查 → 轻提示 → 更新说明 → 浏览器下载 → 手动安装」。
客户端更新与音乐服务端、登录状态和自定义后端地址无关，无需升级 Go 后端。

## 检查与提示

- 版本来自 PackageInfo；官方版本来自固定的 zenpe/CyreneMusic GitHub Releases。
- 只接受正式 vX.Y.Z 标签，排除草稿、预发布及降级。构建号不参与更新比较。
- 首页就绪后自动检查；恢复到前台时可再次检查。成功后 24 小时内不重复请求，
  失败后冷却 15 分钟。手动检查不受冷却及忽略版本限制，并发请求合并。
- 「自动检查更新」沿用 auto_update_enabled 偏好，新安装默认开启。
  此开关只控制检查，不会触发下载、安装或浏览器。
- 自动发现仅在当前可见首页轻提示一次，不弹窗。新版本标记保留在关于入口。
  「启动时显示更新提示」关闭后，检查和关于页标记仍保留。
- 「稍后」在本次运行不再提示；「忽略此版本」跨重启生效，新版本仍会提示。
- 自动检查失败保持安静；手动失败明确显示检查失败，可重试或访问发行页。
  不能连接 GitHub 时不会误报已是最新版本，也不会清除已有版本缓存。

## 下载与安装

更新详情展示版本、发行说明和安装说明。下载完全交给外部浏览器。
应用不下载更新文件、不执行安装、不退出、不提权、不声称更新已完成。

- Windows x64：匹配 cyrene_music-windows-x64.zip。下载完成后退出程序，
  将 ZIP **全部内容**解压至原程序目录并确认覆盖；不能只替换 EXE。
  程序目录应专用于应用；如将来发行版本删除或重命名运行库，应提供明确的
  目录清理说明，必要时解压至新目录启动。用户数据不应存放在发行包内。
- Android arm64：匹配 app-release.apk，下载后覆盖安装，无需卸载。
  发行流程保持 applicationId、签名一致，并增加 versionCode。
- 没有精确匹配的包或不支持的架构：只提供发行页，不猜测文件名或兼容性。
- 浏览器启动失败：界面保留可选择复制的官方发行页地址，用户可自行打开。
- 下载失败由浏览器重试或重新访问发行页；应用保持可用，不涉及半安装状态。

## 发布约束与验证

见 [release.md](release.md)。每次发行递增语义版本及构建号，不替换已发布资产。
CI 保持草稿上传完整包后才公开，客户端只读取正式发行版本。

自动测试覆盖：正式标签与版本比较、精确资产与官方 URL、偏好迁移、缓存与冷却、
手动检查及并发请求、网络/响应错误、忽略版本、主题界面、浏览器失败及关闭检查弹窗。

发行前人工验证：Windows 和 Android 各从旧版本进入关于页，查看更新说明、
在浏览器下载并覆盖安装，确认版本更新且账号、服务地址、歌单等用户数据保留。
Android 补验签名一致及系统安装授权；Windows 补验退出后完整 ZIP 覆盖。
这些实际安装步骤不由单元测试代替。
